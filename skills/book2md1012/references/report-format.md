# 报告格式

抽检的产物都放在 `<书>/_数据/过程报告/`：

| 文件 | 谁写 | 内容 |
|---|---|---|
| `抽检初筛.json` / `抽检初筛.md` | `audit_scan.py scan` | 零花费初筛的疑点与建议抽查页 |
| `抽检-事实清单.json` | 主代理汇总模板 A 的结果 | AI 从低清页图列的事实 |
| `抽检-比对.json` | `audit_scan.py compare` | 事实清单与正文对不上的页 |
| `抽检-审读.json` | 主代理汇总模板 B 的结果 | 逐页 `no_issues` / `issues` |
| `抽检报告-<YYYY-MM-DD>.md` | 主代理 | 给用户看的总报告（格式见下） |

## `抽检-审读.json`（机器读）

```json
{
  "book_dir": "D:/…/新史學",
  "mode": "抽检",                       // 抽检 或 通读
  "pages_read": [6, 13, 18],
  "random_pages": [5, 9, 20],            // 随机抽的页（算三分之一法则用）
  "results": [
    {"page": 5, "file": "01-中國之舊史.md", "status": "no_issues"},
    {"page": 6, "file": "01-中國之舊史.md", "status": "issues", "issues": [
      {"id": "p6-1",
       "block_type": "page_footnote",    // 块类型，见 issue-taxonomy.md
       "error": "missing",               // 错误种类
       "severity": "high",               // high / medium / low / info
       "evidence": "页图下方第 3 条注，起首「〔演示注〕四庫：指清乾隆時所修」",   // 页图证据
       "image": "C:/…/新史學-p0006-150dpi.png",                              // 证据图
       "locate": "試一翻四庫之書[^5]",                                       // 正文定位片段
       "suggestion": "在 [^4] 定义后补 [^5]，注文照原图",                   // 建议改法
       "replacement": null,
       "confidence": 0.95,               // 把握，0–1
       "source": "AI 审读"               // AI 审读 / 初筛 / 初筛+AI 确认
      }
    ]}
  ]
}
```

- 每条问题都要有：类型（`block_type` + `error`）、严重度、页图证据（`evidence`，`image` 可选）、正文定位片段（`locate`）、建议改法（`suggestion`）、把握（`confidence`）。
- `id` 用 `p<页>-<序>`，用户说「改 p6-1、p9-2」时按它找。
- 初筛疑点经 AI 确认的，`source` 写「初筛+AI 确认」；AI 判为误报的不进 `issues`，记在报告的「初筛误报」一节。

## `抽检报告-<日期>.md`（人读）

```markdown
# 《书名》抽检报告（YYYY-MM-DD）

## 结论
- 读了 N 页（必查 a 页、结构页 b 页、随机 c 页），其中 k 页有问题，共 m 条（高 x、中 y、低 z）。
- 抽样极限：随机抽的 c 页里错了 e 页。（e = 0 时写：只能说明其余页的错误页比例大约 < 3/c ≈ __%，不能说明没有错。）
- 建议：……（例如「第 x–y 页一带问题集中，建议通读该章」「脚注问题多，建议全书核注」）

## 问题清单
| 编号 | 页 | 类型 | 严重度 | 原图所见 | 正文现状（定位片段） | 建议改法 | 把握 |
|---|---|---|---|---|---|---|---|
| p6-1 | 6（p.2） | 页下注・漏 | 高 | 第 3 条注「〔演示注〕四庫：指…」 | 「試一翻四庫之書[^5]」的注文没有 | 补 [^5] | 0.95 |

## 初筛误报
- 第 x 页「括号不成对」：原文跨段引用，属正常。

## 没读到的页
- 未抽到的页没有核过；初筛只能查出机器能查的问题（见 `抽检初筛.md`）。

## 下一步
- 回复「改 p7-1、p9-2」或「全部按建议改」后，按 references/revision.md 的修订流程逐页修改。
```

类型一栏写中文：块类型中文名・错误种类中文名（如「页下注・漏」「正文段落・多」「标题・结构层级」）。
