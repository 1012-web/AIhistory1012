# 子代理提示词模板

两步法各一个模板。派子代理一律用 Agent 工具、`effort: "high"`（不用 max）；每个子代理一批页，批与批之间可以并行。子代理只读图、只回 JSON，**不改任何文件**。

把 `{…}` 换成实际值。页图路径用绝对路径。

---

## 模板 A：低清页图列事实清单（第一步）

每批约 10 页，图用 `audit_scan.py render --dpi 60` 出的低清图。子代理**不看正文**，只看图，免得被正文带偏。

```text
你在为一本书做抽检。下面是 {n} 张书页图（低清，够数段落和注即可），请只看图，按下面的规则为每页列一份「事实清单」，最后只输出一个 JSON 数组，不要别的话。

页图（PDF 物理页 → 图片路径）：
{page_list，每行「第 N 页：<绝对路径>」}

每页一个对象，字段：
- "page"：PDF 物理页号（照上面给的）
- "paragraphs"：本页正文段落数。从上一页续过来的半段算 1，转到下一页的半段也算 1。标题、表格、图、图题表题、页眉、页脚、页码、页下注都不算。独立成段的引文算 1 段。
- "note_refs"：本页正文里注码（①②、1 2 3 之类的上标或圈码）的个数，表格里的也算。
- "notes"：本页页下注的条数。上一页没排完、续到本页的注文不算新的一条。
- "headings"：本页标题的文字，按出现次序的数组，抄原文；没有就 []。
- "tables"：表格个数（跨页表在本页的部分算 1）。
- "figures"：图片个数（不含表格）。
- "first_chars"：本页正文最前面 10 个字（跳过页眉；标题不算正文，从标题后的正文起；标点可省）。
- "last_chars"：本页正文最后 10 个字（页下注之前）。
- "unsure"：看不清、数不准的字段名数组，例如 ["note_refs"]；都清楚就 []。

规则：
- 只依据图，不猜。看不清的字段照样给出你最可能的数，并列进 "unsure"。
- 页眉、页脚、页码、水印、扫描污点不算任何内容。
- 输出必须是合法 JSON：一个数组，每页一个对象，按页号排序。
```

主代理收齐后写成 `<书>/_数据/过程报告/抽检-事实清单.json`，跑：

```bash
python -X utf8 ${CLAUDE_SKILL_DIR}/scripts/audit_scan.py compare "<书>" --facts "<书>/_数据/过程报告/抽检-事实清单.json" --out "<书>/_数据/过程报告/抽检-比对.json"
```

`抽检-比对.json` 里 `verdict` 为「需高清通读」的页，加上 "unsure" 不为空的页、必查页，进入第二步。

## 模板 B：高清通读（第二步，只读对不上的页）

每批 3～5 页。图用 150～200 dpi（`audit_scan.py render --dpi 150`，或让子代理用 Read 直接按页读 PDF）。给子代理本页正文（`page_tool.py extract --page N --numbered` 的输出）和本页的初筛疑点。

```text
你在审校一本书的 Markdown 正文，依据是书页原图。原图是唯一依据；正文是 OCR 导入的，可能有漏、多、错、串。原书本身印错的地方照录，不算错误（可以作为 info 报出）。

分类规则见：{${CLAUDE_SKILL_DIR}/references/issue-taxonomy.md 的绝对路径}（先读它）。

要审的页：
{逐页给出：
 第 N 页
 页图：<绝对路径>
 正文（带行号，<!--pdf-page.N--> 是本页起点，<!--p.M--> 是印刷页，不要报告锚点注释本身）：
 <extract 的输出>
 初筛疑点：<该页 audit_scan 与 compare 的结果，一行一条；没有写「无」>}

逐页对照：段落有无漏、多、并、拆；页下注是否齐全、注码位置是否对；标题文字和层级；表格行列；页眉页脚页码水印是否混入；错字。专门术语、生僻字、表格里的单字格要逐字对图核：多家识别常犯同一个错（例：一张表里的生僻字被各家都认成形近的常用字，「痾」认成「病」，「沴」认成「诊」，表中「—」认成「一」），不能因为字形常见、读得通就放过。初筛疑点要逐条给结论（确有其事 / 误报）。

只输出一个 JSON 数组，每页一个对象，格式：
{"page": N, "status": "no_issues"}
或
{"page": N, "status": "issues", "issues": [
  {"block_type": "page_footnote", "error": "missing", "severity": "high",
   "evidence": "页图左下第 2 条注，起首「参看……」",
   "locate": "正文里能唯一搜到的一段原文，至少 10 字；漏了的东西写它前面紧挨的那句",
   "suggestion": "在 [^29] 定义后补 [^30]，注文照原图",
   "replacement": {"old": "可选：正文原样", "new": "可选：改成什么"},
   "confidence": 0.9}
]}
另加一个字段 "scan_verdicts"：[{"check": "初筛的 check 名", "line": 行号, "verdict": "确有其事" 或 "误报", "note": "一句话"}]。

规则：
- 只报你在图上确实看到的差异；拿不准的 confidence 写低，并在 evidence 里说明看不清的地方。
- 不改写、不润色；suggestion 只说怎么改回原书的样子。
- 不要报锚点注释、Markdown 语法本身（如 [^n]、# 号）。
- 输出必须是合法 JSON。
```

---

## 全书通读（用户同意花费后）

不分两步：每批 3～5 页直接用模板 B（不给初筛疑点时写「无」）。批数多时分轮派，每轮收齐后先把结果并进报告，再派下一轮，避免一次性失控。
