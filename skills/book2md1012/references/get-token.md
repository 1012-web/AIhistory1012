# 两家云端 API：本机窗口配置

首次安装或使用引导时，两家都介绍、都引导配置。已有有效配置不要求重新输入。**调用云端 API 不需要安装 MinerU 客户端、PaddleOCR 软件、飞桨框架或本地 OCR 模型，也不需要配置显卡/CUDA。** 用户只需开通两家账号并提供 API 令牌；不必设置环境变量或选择技术参数。运行 skill 脚本仍需本机 Python 和配套脚本依赖，由 AI 负责配置；令牌不发到聊天里。

## 默认：AI 打开一个本机窗口

由 AI 启动以下脚本，用户只在弹出的窗口操作。Windows 在后台启动并隐藏控制台窗口，保留图形窗口；不要让普通用户手抄命令。脚本独立于 Obsidian；图形窗口需要 Python 的 Tk 图形组件和可用桌面会话，不依赖 MinerU/PaddleOCR 客户端。

```powershell
python -X utf8 "${CLAUDE_SKILL_DIR}/scripts/configure_tokens.py"
```

在同一条入门说明里给完：

1. 窗口内点 MinerU 的「打开官网获取令牌」，登录/注册后在 [API 管理](https://mineru.net/apiManage) 创建并复制 API Token，粘贴到 MinerU 输入框。
2. 点 PaddleOCR 的官网按钮，登录 [飞桨星河 PaddleOCR](https://aistudio.baidu.com/paddleocr)，复制该服务的 Access Token，粘贴到 PaddleOCR 输入框。不是本地模型下载，也不是其他百度服务的 API Key。找不到入口时仅截官网不含令牌的页面，按实际页面指导。
3. 点「保存令牌」。保存不联网；留空的服务不覆盖原令牌，已存令牌不会填回输入框。Windows 复用现有 DPAPI 加密，macOS/Linux 目前是 `0600` 权限文件、未加密，窗口会说明。
4. 可分别点击验证。MinerU 查询认证与用量，不上传 PDF。PaddleOCR 显示确认框，说明会提交程序生成的 1 页空白 PDF、可能消耗 1 页额度；确认后才提交，不发送用户文献。验证通过只表示认证和接口/测试任务可用，不代表具体文献已正确识别。

保存与验证分别显示，不能把「已保存」说成「验证通过」。网络验证在后台运行，不阻塞窗口。用户在窗口输入期间，AI 不读取输入框、不截取窗口、不记录剪贴板内容；保存后也不读取或打印令牌。

窗口沿用原客户端的环境变量优先规则：`MINERU_API_TOKEN`、`PADDLEOCR_ACCESS_TOKEN` 若存在，窗口会提示当前使用环境变量；本机新保存值不会替换它，验证结果也标明验证的是环境变量。不能声称新存值已验证，不能未经授权改用户环境变量。

账号登录、验证码、实名和购买额度由本人操作。PDF 正式识别会发往两家服务；额度、资费和账号条件以控制台为准，不承诺永久免费。

## 令牌过期与面板提示

MinerU 令牌有有效期，以官网显示为准；不要把本机保存日期加三个月当成准确到期日，也不要说成 API 接口每三个月必须升级。

- `A0211`：令牌过期。面板在 MinerU 一栏显示红色提示，指导点击官网按钮生成新令牌、粘贴、保存并重新验证，不必重装。
- `A0202`：令牌错误。提示复制完整令牌，不带 `Bearer` 前缀或引号，必要时重新生成。
- 只有 HTTP 401/403 时：只能说明认证或权限有问题，不断言一定过期。
- 限频/额度受限、网络失败与超时有分别提示，不引导用户反复重装或换令牌。

面板是配置与手动验证工具：启动不联网，不定时监控到期，也不自动接收后台 OCR 任务的失败通知。实际导入遇到认证错误时，由 AI 根据原客户端返回的状态码说明原因并重新打开配置窗口；不能声称窗口会自动弹出。保存不会自动验证，点击验证后才依据服务响应提示。窗口不回显服务端原始错误正文，以免其中夹带凭据。

官方依据：[MinerU API 错误码](https://mineru.net/apiManage/docs)。

## 换电脑与运行条件

换电脑后重新安装 skill 及 Python 脚本依赖，并在新电脑本机窗口输入令牌。Windows 的 DPAPI 密文通常绑定原 Windows 用户和电脑，不能把配置文件复制过去就当作令牌已迁移；不复制本机绝对路径，安装器按新安装位置生成路径。网络需能访问两家 API。当前已有证据来自本机，不能将其描述成已经完成所有操作系统或另一台电脑的实测。

## 没有图形界面时保留命令行

Python 缺少 Tk 或机器无图形会话时，脚本返回 `GUI_UNAVAILABLE`。这时解释原因，再让用户在本机终端逐条隐藏输入；不要悄悄替用户另装桌面依赖。

```powershell
python -X utf8 "${CLAUDE_SKILL_DIR}/scripts/mineru_api.py" configure
python -X utf8 "${CLAUDE_SKILL_DIR}/scripts/paddle_api.py" configure
```

原命令行、环境变量和 PaddleOCR 令牌文件用法不变。后续正常任务自动读取配置；失效时重新打开配置窗口帮助更新，不自行降为单家完成。
