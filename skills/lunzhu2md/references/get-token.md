# 帮用户拿令牌（不懂 AI，但不是傻子）

他能读、能点、能复制，缺的只是**入口在哪**和**术语翻译**。不要把"不懂"当成"需要被喂"。

## 默认：一条消息说完

直接发这一段（把路径换成实际的）：

> MinerU 要一串"访问令牌"——相当于给程序的临时密码，只存在你本机，不用发给我。三步：
> 1. 打开 `https://mineru.net`，右上角登录（手机号收验证码，免费）；
> 2. 进控制台，找带 **API** 或 **令牌** 的那一项，新建一个，复制那串字符；
> 3. 开 PowerShell（Win 键搜「PowerShell」），跑下面这条，把令牌粘进去回车——**屏幕不显示任何字符是正常的**：
>    `python -X utf8 <技能目录>/lunzhu2md/scripts/mineru_api.py configure`
> 看到 `CONFIGURED` 就好了。哪一步卡住跟我说，或者截个图。

一次就够。他回一句，**你自己验证**（见下），不要追问他"成功了吗"。

## 验证由你来做

```bash
python -X utf8 <技能目录>/lunzhu2md/scripts/mineru_v1.py usage
```

打得出用量 = 令牌有效；报 401 = 复制时带了空格或令牌已失效。

## 只有真卡住才拆步

| 他说 | 你怎么办 |
|---|---|
| 找不到令牌入口 | 要截图，按图指位置；别硬背按钮名，页面会改版 |
| 粘贴进去没反应 | 正常，确认按了回车；再不行让他先粘记事本、再从记事本复制过去 |
| 要实名认证 | 让他按页面做，只能本人；做完回到第 2 步 |
| 报 401 | 令牌抄错或失效，重来第 2 步 |
| 令牌只显示一次，没复制 | 重新建一个，这次先粘进终端再关页面 |

## 不要做的

- **不要一步一问等他确认**——六个来回换一个令牌，既慢又冒犯人。
- 不要替他注册、收验证码、实名、绑卡。
- 不要索取令牌、不要复述令牌。
- 不要把按钮名说成唯一答案。
