# 帮用户拿令牌（当他完全不懂 AI）

这里的用户不是开发者：不知道什么是 API、没听说过"控制台"、看到一长串字符会以为要自己记住。
下面的流程是**给他一步步走**的，不是给他读的。

## 你在对话里怎么带

1. **一次只给一步**，说完等他说"好了/看到了"再给下一步。别一口气贴五步。
2. **先说他能看到的**，再说术语。「打开一个网页，右上角有『登录』」比「去控制台创建 API Key」有用。
3. **卡住就截图**：让他把当前页面截图发你，你看图告诉他点哪。页面改版是常态，截图比文字可靠。
4. **绝不索取令牌本身**。不让他把令牌发到聊天里，也不替他粘——只告诉他"在终端粘贴，屏幕不会显示"。
5. 他没做过的操作（开终端、粘贴、回车）也要说清楚：Windows 按 Win 键搜「PowerShell」，Mac 搜「终端」。

## A. MinerU（必配，导入要用）

**第 1 步**：告诉用户打开 `https://mineru.net`。
「这是把 PDF 转成文字的网站，我们要用它的服务。」

**第 2 步**：注册/登录。
「右上角点『登录』，用手机号收个验证码就行，不用付费。」

**第 3 步**：找令牌入口。
「登录后进『控制台』或『个人中心』，找带 **API**、**令牌**、**Token**、**密钥** 字样的那一项。
找不到就把这个页面截图发我。」

**第 4 步**：复制。
「点『新建令牌/创建 API Key』，会给你一串字母数字（很长）。复制它。
注意：有的页面**只显示一次**，关掉就看不到了，看不到就重新建一个。」

**第 5 步**：粘进终端，不要粘进聊天。
「开一个 PowerShell 窗口，运行下面这条命令，然后粘贴、回车。**屏幕不会显示任何字符**，粘贴完直接回车就行：

```
python -X utf8 <技能目录>/lunzhu2md/scripts/mineru_api.py configure
```

看到 `CONFIGURED` 就好了。」

**第 6 步**：验证（你来做，别让他做）。

```bash
python -X utf8 <技能目录>/lunzhu2md/scripts/mineru_v1.py usage
```

能打出用量说明令牌有效；报 401 就是复制时带了空格或令牌失效，让他重来第 4 步。

**常见卡点**

| 他说 | 你怎么办 |
|---|---|
| 「要实名认证」 | 让他按页面提示做，这步只能本人；做完回到第 4 步 |
| 「找不到 API 在哪」 | 要截图，按图指位置；仍没有就让他问页面里的客服/帮助 |
| 「令牌显示一次就没了」 | 重新建一个，这次先粘进终端再关页面 |
| 「粘贴进去没反应」 | 正常，输入不显示；确认回车了 |

## B. PaddleOCR（可选，第二家识别才用）

**先说清楚要不要**：这一步是为了"第二个人再读一遍"，没有也能导入，只是报告里会写「无第二读者覆盖」。
用不用让他自己决定，别默认推。

**第 1 步**：`https://paddleocr.aistudio-app.com`（百度飞桨星河社区的 OCR 服务）。
用百度账号登录，没有就手机号注册。

**第 2 步**：开通/创建应用。
页面里找「创建应用」「获取 Access Token」「API 调用」之类入口；找不到就截图。

**第 3 步**：复制那串 Access Token。

**第 4 步**：同样粘进终端，不进聊天：

```
python -X utf8 <技能目录>/lunzhu2md/scripts/paddle_api.py configure
```

**第 5 步**：你验证：

```bash
python -X utf8 <技能目录>/lunzhu2md/scripts/paddle_api.py status
```

`CONFIGURED` 就好；`NOT_CONFIGURED` 说明没存上（可能粘错窗口）。

**常见卡点**：要实名；每日页数有上限（超了会报错，报告里记哪几页没跑）；免费额度用完要等第二天。

## 你不能替他做的

- 收验证码、实名认证、绑卡付费——只能本人。
- 记住或转述令牌——不要让他发给你，也不要你复述。
- 页面改版后的具体按钮位置——以他的截图为准，不要硬套上面的文字。

## 一句可以直接发的话

> 我们要用一个叫 MinerU 的在线服务把 PDF 转成文字，它需要一串"访问令牌"（相当于给程序的临时密码，别人拿到会用你的额度）。
> 我把步骤一步步发你，你做完一步回我一声就行。令牌不用发给我，你自己粘到终端里，屏幕上不会显示。
